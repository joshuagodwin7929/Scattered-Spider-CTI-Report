# Scattered Spider Threat Intelligence Report

CTI report on Scattered Spider (UNC3944), built from open-source reporting and mapped to MITRE ATT&CK. It comes in two versions.

## What's inside
- Actor profile and key incidents
- Tradecraft and MITRE ATT&CK mapping
- Detection and defense recommendations
- Sourced references

## Read the report
- [2-page brief](./Scattered_Spider_CTI_Brief.pdf): the short version for a quick read
- [Full technical report](./Scattered_Spider_Full_Technical_Report.pdf): the evidence, full ATT&CK table, timeline, and sources

## Method
Compiled from CISA/FBI advisory AA23-320A, MITRE ATT&CK G1015 (v17), and public vendor and press reporting. Classification: TLP:CLEAR.
